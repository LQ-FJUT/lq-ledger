# L.Q记账

> 简明安装与使用说明见 [项目介绍与使用指南](项目介绍与使用指南.md)。

完全离线的个人消费账本。此仓库从零开始构建，不依赖微信、CloudBase 或任何在线账户。

## 已实现的 1.3 功能

- 单用户、人民币、仅支出；金额用整数“分”保存。
- 5 个一级分类、22 个末级分类；可增删改分类并保留历史分类快照。
- 快速记账、最近分类、地点联想、复制上一笔、金额算式、常用模板、键盘提交、保存后连续记账。
- 按月/关键词/一级或末级分类/日期/金额查记录，稳定分页、汇总、软删除、事务化批量恢复和永久清除。
- 月度统计、正确的一级分类下钻、上月对比、日均/最高消费日、六个月趋势、一级与末级分类预算、复制上月预算。
- 完整 JSON 备份与恢复（恢复前自动备份当前账本并深度校验）；CSV 只作 Excel 报表。
- 分类排序、恢复、同级末级分类完整合并预览、预算/模板迁移、地点隐藏与重新启用。
- 备份页显示最近导出摘要、SHA-256 校验状态、导入前自动备份，并可配置保留 30 份的每日滚动备份。
- 跟随 Windows/浅色/深色主题、舒适/紧凑密度、统一确认对话框、键盘焦点与减少动画支持。
- Tauri 2 + Vue 3 + SQLite，Windows 安装包使用 NSIS 当前用户安装模式；卸载不删除应用数据。

## 开发与验证

```powershell
npm install
npm test
npm run build
npm run desktop:dev
```

生成 Windows 安装包：

```powershell
npm run desktop:build
```

安装包会输出到 `src-tauri\target\release\bundle\nsis\`。首次在没有 WebView2 Runtime 的电脑上安装时，安装程序可以下载微软 WebView2；应用日常运行不联网。

## 数据位置与恢复

- SQLite 数据库和“导入前自动备份”由 Tauri 放在当前 Windows 用户的应用数据目录；预算与常用模板随数据库迁移保存。
- 可在“设置 → 备份与恢复”选择每日备份目录；目录设置仅留在本机，不写入迁移备份。
- 通过“设置 → 备份与恢复 → 导出完整 JSON”自行选择长期备份位置。
- JSON 完整备份是未来 Android 版本的人工迁移格式；CSV 不能恢复账本。
